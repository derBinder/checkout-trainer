# App-Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Der Checkout-Trainer zeigt im Browser-Tab und als installierte App ein eigenes Icon.

**Architecture:** `src/app/icon.svg` ist die einzige Quelle. Ein Skript rechnet daraus alle PNGs und die ICO-Datei, die erzeugten Dateien sind committet. Next.js verlinkt `icon.svg`, `favicon.ico` und `apple-icon.png` über die Datei-Konvention, das Manifest nennt die PNGs unter `public/`.

**Tech Stack:** Next.js 16 Datei-Konvention für Metadaten, `sharp`, `tsx`, Vitest

**Spec:** [docs/superpowers/specs/2026-11-26-app-icon-design.md](../specs/2026-11-26-app-icon-design.md)

## Global Constraints

- Farben: Grund `#0b0b0c`, Ring und Mittelpunkt `#ffd400`
- Raster 100 × 100: Eckenradius 22, Ring Radius 30 mit Strichstärke 7, Mittelpunkt Radius 9
- Jede Icon-Adresse behält ihre Dateiendung, sonst leitet `proxy.ts` sie um
- Keine neue Abhängigkeit in `package.json`
- Vor dem Commit `npm run test:coverage`, `npm run typecheck` und `npm run lint`

## Review Focus

- Root-Layout unter `[lang]`: Der Seitenkopf von `/de/sign-in` und `/en/sign-in` muss trotzdem `icon` und `apple-touch-icon` verlinken. Geprüft in Task 1 und 3 im Browser.
- Größe im Manifest weicht von der Datei ab: Chrome verwirft den Eintrag. Der Test in Task 2 liest die echte Größe aus dem PNG-Kopf.
- Icon-Adresse ohne Endung: `proxy.ts` leitet mit 307 um. Geprüft in Task 3 mit `curl -I`.
- Ring bei 16 Pixeln unter einem Pixel: Das Icon verschwimmt im Tab. Geprüft in Task 2 am erzeugten Bild.
- Transparente Ecken im Apple-Icon: iOS füllt sie schwarz oder weiß. `apple-icon.png` ist randlos und deckend.

- [ ] **Step 1: Test zuerst.** In `src/app/manifest.test.ts`:

```ts
it("nennt App-Icons, die mit der genannten Größe unter public/ liegen", () => {
  const icons = manifest().icons ?? [];
  expect(icons.map((i) => [i.src, i.sizes, i.purpose])).toEqual([
    ["/icon-192.png", "192x192", "any"],
    ["/icon-512.png", "512x512", "any"],
    ["/icon-maskable-512.png", "512x512", "maskable"],
  ]);
  for (const icon of icons) {
    const png = readFileSync(join(process.cwd(), "public", icon.src));
    // PNG-Kopf: Breite und Höhe stehen als 32-Bit-Zahlen ab Byte 16 und 20.
    expect(`${png.readUInt32BE(16)}x${png.readUInt32BE(20)}`).toBe(icon.sizes);
  }
});

it("startet auf schwarzem Grund wie das Icon", () => {
  expect(manifest().background_color).toBe(THEME_COLORS.dark);
});
```
